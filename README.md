# Gray Crown — 整理版（v23）

## ゲームを起動する

1. ZIPを展開します（ZIP内から直接実行せず、先に展開してください）。
2. このフォルダ直下の **index.html** をブラウザで開きます。
3. ゲーム本体は `index.html` / `css/` / `js/` / `assets/` にあります。

## フォルダ一覧

- `index.html` — ゲーム起動ファイル
- `css/` — 画面デザイン
- `js/` — ゲームのプログラム
- `assets/` — ゲーム画像（現在使用中の画像と復元・比較用画像を保持）
- `docs/` — 設計書・監査資料・過去の開発履歴
- `docs/history/` — 旧版レポート（以前ルート直下にあったTXT文書）
- `tests/` — テスト
- `package.json` — 開発用テスト設定
- `README.txt` — v23の説明

## 注意

これは **main を変更しない文書整理版** です。ゲーム本体、セーブ仕様、テストコード、画像の内容は変更していません。ブラウザ実行・テストの成功を保証するものではありません。

過去の報告書は削除せず `docs/history/` に移しました。復元・比較に使う可能性のある画像もそのまま残しています。

元の制作基準: `docs/audit/CURRENT_PROJECT_STATE.md`。

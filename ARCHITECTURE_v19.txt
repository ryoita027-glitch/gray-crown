灰冠の勇者たち — Architecture Refactor v19

目的
v19はコンテンツ追加版ではない。Alpha 2.0を作る前に、戦闘変更がストーリー進行を壊すようなモノリス構造を解体し、責務・状態・イベント・テストを固定するためのリファクタリング版。

1. 実行構成
ブラウザで index.html を直接開く運用を維持するため ES Modules は使用せず、classic script を読み込み順固定で使用する。
各モジュールは window.GC 名前空間へ公開APIを登録する。

core/
- dom.js: DOM/canvas定数と共通参照
- state.js: 新規ゲームStateの生成・置換・リセット
- save.js: 保存、バックアップ、v18以前の移行、破損値検証、安全座標補正

data/
- items.js: 成長・EXP・スキル・パーティ基礎値
- maps.js: マップ、宝箱、ショートカット、遷移定義
- npcs.js: NPC/パーティ描画定義・ポートレート
- battles.js: 戦闘定義
- events.js: Alpha 1.0のイベントデータ（条件・会話・効果）

systems/
- story.js: Story/World/Event状態API、旧フラグ移行互換
- dialogue.js: タイプライター、送り、選択肢
- events.js: EVENT_DEFSを評価・再生するイベントエンジン
- movement.js: 移動、衝突、地域遷移
- exploration.js: 宝箱、回復、店、ショートカット
- battle.js: 戦闘ロジック、シンボル戦復帰
- progression.js: EXP/レベルアップ
- audio.js: BGM/SE
- menu.js: メニュー

render/
- world.js: ワールド描画のみ
- battle.js: 戦闘画面・演出描画のみ
- ui.js: HUD/UI更新

legacy/
- events-legacy.js: Alpha 2.0以降の旧スケルトン互換専用。
  新規コンテンツをここへ追加してはいけない。

2. State v19
保存対象は以下の構造を正本とする。

story
- stage: 00_village ～ 08_alpha_complete
- chapter
- objective

quests
- main: メイン進行
- active: 進行中クエスト
- completed: 完了クエスト

world
- visited: 到達済みマップ
- switches: 扉、レバー、サービス購入など世界状態
- defeatedSymbols: 撃破済みシンボル
- treasures: 取得済み宝箱
- shortcuts: 開通済み近道
- recoveryUses
- finalChoice

events
- completed: 一度きりイベント完了
- choices: プレイヤー選択結果

旧 state.flags は非列挙Proxyとしてv18以前の移行・旧スケルトン互換だけに残す。
新セーブには flags を保存しない。
legacy/events-legacy.js 以外の直接 state.flags 参照は自動テストで禁止する。

3. データ駆動イベント
Alpha 1.0の重要イベントは data/events.js に定義する。
各イベントは以下を持つ。
- id
- trigger: npc / object / battleWin
- when: 発生条件
- lines / postLines: 会話データ
- effects: completeEvent / advanceStory / worldSwitch / visit / defeatSymbol / recoverParty / journal 等

systems/events.js が条件判定・再生・効果適用を担当する。
Alpha 2.0の本番イベントはこの方式でのみ追加する。

4. 互換方針
- v18以前のflat flagsは load 時に story/world/events へ移行。
- relayvillage / ravine の旧セーブ座標補正を維持。
- 通常セーブ破損時はバックアップから復旧。
- 旧スケルトンは当面動作可能だが、新規依存は禁止。

5. Alpha 2.0開始条件
以下を毎回 npm test でPASSすること。
- モジュール構成
- Story 00→08
- save→reset→load
- v18旧セーブ移行
- シンボル戦→元座標/向き復帰
- One-shot再発防止
- マップ遷移座標/向き
- レベルアップ
- legacy以外の state.flags 直接参照ゼロ

この条件を崩した状態でAlpha 2.0のシナリオを追加しない。

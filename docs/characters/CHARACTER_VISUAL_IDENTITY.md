# 0. この資料の役割

`CHARACTER_SHAPE_LANGUAGE` が「4人を別人にする」ための基準であるのに対し、本資料は、

> **4人をそれぞれ“見た瞬間に興味を持てる人物”として成立させるための視覚的アイデンティティ**

を固定する。

魅力は装飾量ではなく、

- 顔
- 身体
- 姿勢
- 髪
- 色面
- 衣装の大きな形
- 着こなし
- 動いた時のシルエット

の選択によって作る。

4人は全員23歳の成人女性である。全員を同じ顔・同じ細腰・同じ脚比率・同じ微笑みにしない。

# 9. Triton A — GROUND ANCHOR

## 方向性

**「強そう」より先に、“立っているだけで安定して見える”強さを作る。**

筋肉や鎧を盛るのではなく、肩・足幅・重心・衣服の水平線で身体的説得力を出す。

## 第一印象

**頼れる / 健康的 / 地に足がついている / 思ったより話しやすそう。**

> 「この人が横にいたら倒れなさそう」

という感覚を狙う。

## 髪

- 肩に触れる程度の暗髪。
- 毛先は重めで、細かく跳ねさせない。
- 前髪は片側へ自然に分かれ、切れ長の目と直線眉を隠さない。
- 結ばず、後頭部〜肩へ一つの重い形で落とす。
- 横から見ると首後ろに量感があるが、背中までは伸びない。
- 後ろは横幅のある台形〜丸角四角に近い塊。
- 走る時も髪全体が大きく跳ねず、毛先だけ遅れて動く。

Karenの「結び＋揺れ」と明確に区別する。

## 顔周辺

顔横を細い毛束で囲わない。頬〜顎を比較的開き、広めの口と顎線を見せる。

襟は首を締めすぎず、肩線が分かる構造にする。

## Stage A衣装

**剣術稽古で長く使ってきた丈夫な生活服。**

- 生成り〜灰の基礎上衣。
- 青は胴体中央ではなく、**腰〜脇の大きな実用布面**へ置く。
- 前腕に簡素な防護 / 稽古用補強。
- 肩と背中の可動域を妨げない。
- 下半身は太腿〜膝が動かしやすい。
- 革部品はKarenより一段丈夫。
- 装備は身体へ密着して揺れを少なくする。

## 色面

青は**腰・脇に広い一塊**。上半身中央は生成り / 灰、革と鉄色で地に足をつける。

帝国の深青＋黒＋銀とは違い、自然染料的で少し褪せた青。

## 主フック

**肩幅＋低い重心＋腰に置かれた青い横長色面。**

## 副フック

重めの肩丈暗髪。

## 職業外個性

武器を隠しても、

- 足をしっかり置く
- 肩をすぼめない
- 広めの口で豪快に笑う
- 人を見る時だけ視線が鋭く止まる

ことで、**「身体感覚が良く、頼れる友人」**に見える。

## シルエット

4人で最も横方向が強い。

肩と腰の安定した横線、低い中心、短い髪量。遠景では「高い人」より「安定した人」と読む。

## Stage Bへの発展

横長の青色面を維持したまま、防具量を4人で最も増やせる。肩を巨大化せず、胸・前腕・腰・脛へ機能防具を足す。

## 弱点

整理しすぎると一般兵 / 兵士NPCに近づく。顔・笑い方・髪量で本人らしさを残す必要がある。

## 既視感リスク

**低〜中。**

# Gray Crown — Environment Prototype Scope v1

Status: PROVISIONAL / research lane only.

The prototype is limited to exactly four visual studies:

1. **Prototype A — Village micro-area**
2. **Prototype B — Grass field micro-area**
3. **Prototype C — House exterior**
4. **Prototype D — House interior**

Do not expand before user visual PASS into castles, the capital, full forests, caves, Imperial cities, NPC towns or mass housing.

These images are not production maps. They do not replace `js/data/maps.js`, collision, story, Save schema, or runtime environment assets.

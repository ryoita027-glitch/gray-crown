# PIXEL_CHARACTER_ACTING.md

## Gray Crown — Four Hero Acting Identity

**Status:** PROPOSAL BASED ON LOCKED VISUAL IDENTITY  
**Important:** Visual Identity自体は変更せず、動作へ翻訳する。

---

# 1. 共通原則

4人を同じAnimation setの髪色違いにしない。

Common animationでも、

- 重心
- start speed
- stop speed
- arm range
- head turn
- interpersonal distance
- hold duration

を変える。

感情は顔差分だけでなく、

> **Face + Body + Pose + Direction + Movement + Timing**

で表現する。

---

# 2. Karen — VILLAGE RUNNER

## Acting Core

**身体全体で感情が出る。**

Movement:
- 歩き出しが早い
- 人へ向かう初速が速い
- Stop後も上半身が少し前へ残る
- 振り向きが速い
- 相手へ自然に半歩近づく
- 仲間を呼ぶ時は身体ごと向く

Emotion:
- Smile: 肩が開く
- Laugh: 身体全体が1〜2px上下
- Surprise: 足と上半身も反応
- Angry: 一歩前へ
- Worried: 一度止まるが最終的に近づく

Battle identity:
- left-handed
- sword right hip
- draw left hand

Signature:
1. Quick Approach
2. Whole-body Laugh
3. Fast Look-back Run

---

# 3. Triton — GROUND ANCHOR

## Acting Core

**重量 / 安定 / 守る / 地面。**

Movement:
- startはKarenより一拍遅い
- stepに重量
- Stopが明確
- Idleで足幅がやや広い
- 不必要に身体を揺らさない
- 警戒時は首だけでなく肩向きも変える

Emotion:
- Laugh: Karenほど跳ねない
- Surprise: 後退せず姿勢を固める
- Angry: 位置を変えず重心を落とす
- Protect: 誰かと脅威の間へ一歩入る

Signature:
1. Anchor Shift
2. Step Between
3. Short Broad Laugh

---

# 4. Sophie — STEADY HANDS

## Acting Core

**演技の焦点は手。**

Movement:
- 歩幅は4人で最小
- 速さより確実に近づく
- しゃがむ / 支えるが自然

Hand language:
- Reach
- Support
- Receive
- Give
- Check wound
- Touch shoulder
- Hold cloth / medicine

Emotion:
- Smile: 小さく、手の緊張がほどける
- Worried: 一歩近づき、手が先に動く
- Angry: 逆に動きが止まる
- Serious: 手の位置が決まり迷わなくなる

Signature:
1. Reach and Check
2. Steady Support
3. Still Anger

「小柄で可愛い」だけにしない。

---

# 5. Margaret — MEASURED LINE

## Acting Core

**数Pixelの変化とTimingで演技する。**

Movement:
- startは急がない
- Stopが正確
- postureの縦線を崩しにくい
- 視線→首→身体の順で向く
- 人との距離は少し保つ

Acting tools:
- gaze
- head direction
- book / note
- small hand movement
- pause
- delayed answer
- measured turn

Emotion:
- Surprise: 小さな頭の動き＋一拍の停止
- Angry: 大きく動かず視線と姿勢が硬くなる
- Think: 視線を資料へ落とす
- Serious: 動作が減る

Signature:
1. Measured Glance
2. Check / Mark Note
3. Delayed Answer

Hair is **WHITE / SILVER-WHITE**. Never revert.

# 6. Common Animationに個性を入れる

## Idle
- Karen: forward-ready
- Triton: low stable
- Sophie: hands calmly near work position
- Margaret: vertical, minimal

## Walk
- Karen: fast start, larger arm/body rhythm
- Triton: weighted, stable
- Sophie: smaller steps
- Margaret: straight and economical

## Turn
- Karen: fast whole-body
- Triton: planted pivot
- Sophie: small careful turn
- Margaret: gaze/head precedes body

## Talk
- Karen: torso + hand
- Triton: restrained shoulder/hand
- Sophie: hands toward other person
- Margaret: small head/hand

---

# 7. Interpersonal distance

Karen:
- 4人で最も近づきやすい。

Triton:
- 平常は適度な距離。守る時だけ一気に間へ入る。

Sophie:
- 治療・心配時に距離を詰める。

Margaret:
- 平常は少し距離を保ち、必要な時だけ近づく。

# 8. 不合格

- 全員同じIdle bob
- 全員同じTalk hand wave
- 全員同じSurprise jump
- 全員同じLaugh bounce
- MargaretがKarenと同じ大きさで動く
- Sophieが小動物的cuteだけになる
- Tritonが常に怒って見える
- Karenの左利きが消える

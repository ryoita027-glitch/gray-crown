# Gray Crown — Pixel Character Standard v2 (Four-Protagonist Prototype)

**Status:** PROTOTYPE AUTHORITY — NOT MAIN ADOPTION  
**Supersedes for new work:** Pixel Character Standard v1 provisional workflow order  
**Evidence:** Karen + Triton + Sophie v2 + Margaret v5

## Core result

Four deliberately different protagonists now operate under one 48×48 / Medium44 runtime architecture without requiring one shared anatomy template.

The production rule is:

> **one technical grammar, four distinct bodies and acting languages, equal readability.**

## Shared technical contract

- source frame: 48×48 RGBA;
- direction order: down / left / right / up;
- logical world: 32px;
- default field/event scale: Medium44;
- nearest-neighbor rendering;
- foot-anchor family centered on [24,44], with deviations requiring evidence;
- exactly eight prototype categories:
  Idle 4 / Walk 6 / Turn 3 / Talk 4 / Surprise 4 / Approach 4 / Laugh 6 / Run 6.

## Cast-specific identity

### Karen — VILLAGE RUNNER
- forward, quick, warm;
- red/red-brown low tie + loose moving hair;
- narrow active body;
- larger whole-body emotional amplitude.

### Triton — GROUND ANCHOR
- broad, planted, low center of gravity;
- heavy dark shoulder hair;
- restrained vertical motion;
- wider/horizontal mass.

### Sophie — STEADY HANDS
- smallest protagonist;
- soft adult body;
- honey gathered/braided hair;
- cream + brown + muted green;
- hands lead acting;
- active technical source is v2 cleanup lock.

### Margaret
- vertical / measured identity;
- pale silver-lavender simple high ponytail;
- dark navy/charcoal + cream;
- calm intelligent face;
- restrained motion;
- active prototype source is v5 face-readable lock.

## Unified quality gate

All four must be judged together under:

1. face readability;
2. Medium44 apparent occupancy;
3. head/body balance;
4. outline separation;
5. hair silhouette identity;
6. four-direction stability;
7. eight-animation integrity.

The detailed contract is:

`docs/pixel/FOUR_PROTAGONIST_QUALITY_STANDARD_v1.md`

## Exact comparison rule

Comparison evidence must use exact evaluated PNG pixels.

AI-generated comparison boards are prohibited.

Concept generation may be used separately, but it cannot prove:
- scale;
- face readability;
- silhouette;
- lock equivalence;
- runtime quality.

## Cleanup rule

Technical debris cleanup is permitted when it:
- removes detached accidental pixels;
- does not redraw the approved figure;
- is mechanically reproducible;
- produces before/after exact-pixel evidence;
- is hash-pinned after promotion.

Sophie v2 is the first example of this rule.

## Face-preservation rule

Do not improve apparent occupancy by blindly scaling a protagonist's head.

Margaret v4 demonstrated that body/occupancy correction can destroy face readability.

When a face is already approved/readable:
- keep face pixels 1:1 whenever possible;
- adjust body occupancy below the face;
- strengthen only external silhouette where needed;
- inspect Medium44 before regenerating all animations.

Margaret v5 is the reference example.

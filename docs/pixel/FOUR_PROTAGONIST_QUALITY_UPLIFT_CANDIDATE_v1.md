# Gray Crown — Four Protagonist Quality Uplift Candidate v1

**Status:** CANDIDATE / SAFE BRANCH EVIDENCE / NOT MAIN AUTHORITY

## Evidence-driven findings

The unified exact-pixel gate shows that the four protagonists already have healthy silhouette separation and similar Medium44 visible height, but they are not yet equally clean.

The first correction pass is intentionally conservative:

- **Karen:** control; no redesign. Only detached micro-artifact cleanup is permitted.
- **Triton:** locked control; no redesign. Only detached micro-artifact cleanup is permitted.
- **Sophie:** preserve the approved design, but remove detached pixels above the head that repeat across runtime frames. These pixels are rendering debris, not part of her intended hair silhouette.
- **Margaret:** use the v5 face-preserving direction candidate and regenerate the eight prototype animations from it. This addresses the rejected v4 crushed-face problem without inventing a new design.

## What this pass does not do

It does not:
- normalize everyone to one body;
- force identical palette size;
- recolor character identities;
- smooth/interpolate pixels;
- overwrite locked sources;
- merge to main.

## Promotion rule

Candidate evidence is reviewed first.

If the candidate board is stronger:
1. promote only the proven corrections;
2. preserve Karen/Triton if their candidate is pixel-identical or meaningfully unchanged;
3. promote Sophie debris cleanup as a technical cleanup, not a redesign;
4. promote Margaret v5 to direction authority;
5. regenerate Sophie/Margaret runtime assets;
6. rerun all character locks, browser E2E and full regression;
7. then move to real environment integration.

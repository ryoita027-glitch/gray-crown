- **実Githubソース**をV8で実行。新旧両方で9人×前向きおよび背面を描画できた。旧側のソースセルは32×32、新側48×48。9人のNPC会話像は対応する新PNGを参照しており、顔拡大は64×72に864×384のシートを適切なX値でトリミングした。カレンの既存ポートレートは別関数・無改変。
- 2枚のPNGを実体のPillowデコードで解析。**4方向×9人＝36セルが別画像**、2コマ×9人＝18セルが別画像で各セル可視。透明ピクセル有り、両フレームの足裏アルファが一致。ローカル git blob SHA とGitHubのコミット済みバイナリSHAが一致。
- 保存v35の実ゲームをChromiumで起動し、12,9座標、リュネ村・王都、1280px・390pxで新旧の画面キャプチャ。新画像のリクエスト欠落は0。ブラウザ環境でHTTPS直訪問とlocalhostは管理者ポリシーでブロックされたため、既存の`set_content`と資産ルート提供で描画した。about:blank上のlocalStorage権限エラーは2件残り、**通常セーブ/続きからの証拠ではない**。

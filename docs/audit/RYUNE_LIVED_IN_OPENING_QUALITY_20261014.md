# Gray Crown — リュネ村・西畑・東小川の序盤品質改善（2026-10-14）

## 判定

**HOLD / 商用製品品質未承認。** この改修は序盤の密度・画面の自然さ・音響・プレイ測定を高める **Draft候補**。本編未完成の解消や8～12時間の製品完成を意味しない。

ソース: PR #73（終章改善候補）の上に今回の改修を積む。PR #70/71（序盤エリア・四人のマイクロアクティング）、PR #72（セーブ/配布）を削除・上書きしない。`main`へ未承認コードをマージしない。Story 00–19、Save schema 23、主人公4人の既存48px PNG、当初の北門・王国使者任命条件を維持。

## 制作原則

- **遊びやすく濃密に、ただし寄り道は寄り道のまま。** 新たなマップ数、強制クエスト、長編回想、報酬稼ぎ、無意味なアニメーションで水増ししない。
- 風景が変わるのは、そこで暮らす人々が理由をもって行動した結果のみ。単に見つめた行為では農地・小川が自動で回復しない。
- カレン・トリトン・ソフィ・マーガレットの旧PNG、身体の接地線、カメラ・当たり判定には手を入れない。村人は **持ったパン・工具・ノートと手を合わせる**。歩かないNPCを足踏みさせない。
- 既存の世界観・食品不足・戦争による不安を活かし、詩的演出を乱発しない。

## 実装内容

### 1. 行動が残す小さな物理的な痕跡

`js/render/ryune_outskirts.js` `drawProgress()` は **見せるだけのCanvas描画**。内部では `events.choices` と `events.completed` を読むだけで、書き込み・新アイテム・時間経過はない。

| 場所 | プレイヤー操作 | 控えめな画面の反応 |
|---|---|---|
| 孤児院の既存入口 | 過去の既存選択で薬草を寄付 | 包まれた薬が門口にある。薬草を手元に残した場合には出さない |
| リュネ村・農夫ボルの近く | 西畑と東小川の調査を任意で報告 | 小さな調査メモが道具に加わる。報酬を増やさない |
| 西畑 | 両方の調査内容を農夫に伝えた後 | 苗を避けて溝の測量棒を置く。水が復活したように描かない |
| 東小川 | 同じ報告後 | 岸辺に水位観測の印をつける。川石や水量はそのまま |

現地NPC2人および畑の荷車・川辺の石積みの4つの短い再訪台詞も同じ報告フラグで切替。**各1行、効果なし**。最初の訪問前に後日談が出ることはない。

### 2. 不自然な足踏みの解消

`js/render/opening_worldlife.js` と `js/render/opening_pixel_assets.js` の仕事中の村人に、同じ `workPhase(id,now)` を使用。8～11秒ごとに2つの短い手の姿勢を取り、普段は元の待機姿勢へ戻る。パン屋のトレイなど既存の道具も同じ拍で動かす。住民の足・位置・NPC当たり判定は固定し、座標アニメーションに置き換えない。

- 小川の見回り人などの非作業NPCには歩行・腕振りを割り当てない。
- 近くにプレイヤーがいる時の既存5fps描画に限定。
- OSの「動きを減らす」設定なら静止。
- 読み込み不良のNPCを派手な代用品で隠したり、主人公の48px PNGを上書きしない。

### 3. 水の動きと演出密度

東小川の **元から通行不可の水タイル`Z`のみ**、約700ms単位でハイライトを横2pxずつ移す。プレイヤーが橋周辺に近いときのみ、既存の200msアイドル更新を共有。木橋の`P`床、当たり判定、固定の川岸を動かさない。ブラウザの reduced-motion 設定で停止。

川の流れが実在することを表す最低限の挙動であり、粒子・光線・カメラ揺れ・オブジェクトの勝手な移動は加えていない。

### 4. 家と村から切れない、2つの暫定旋律

`js/systems/audio.js` と `js/systems/commercial_soundscape.js` で `ryuneFields` と `ryuneBrook` を追加。村と同じ音階的な手触りを保持しつつ、畑には働く人の落ち着いた動き、小川には休符の多い薄い旋律。16拍、控えめなゲイン`0.011`/`0.010`。

これは **短いWebAudio合成音による作曲候補**。聞きやすさや商用音楽品質はまだ人間の聴取評価・ミックス・ループ検査が必要。適当に大きな環境音を鳴らさない。

### 5. 既存のゲーム操作から品質を測定

- `tests/browser_ryune_outskirts_e2e_test.py`：通常のNew Gameから西・東の両エリアを **実キーボードで訪問し**、元の選択イベント→村へ報告→再訪の自然な台詞・表示を確認するコード。報告前後のスクリーンショットは計7枚。実歩数・Playwright経過秒数を記録し、セーブ/Continueまで通す。
- `tests/browser_vertical_slice_e2e_test.py`：直前の開発PRから引き継ぐ通常のNew Gameからボス・王都までの通し操作。実戦闘メトリクス（ターン/操作/HP/MP消耗等）を出す。
- `tools/analyze_opening_play_metrics.py`：両テストの **実在するPASS JSON証拠がない場合、失敗して終了**。結果から寄り道歩数、会話比率、戦闘ターン・残り体力、処理落ち候補をまとめる。合成サンプルで品質合格を偽らず、数値を見てから改善案を決める。
- `tests/ryune_lived_in_opening.test.js`：6テスト追加。選択前後のドット描画、OS動作低減、労働アニメーション、4反応の条件、任命イベント保全、3地域の音楽の差分。
- 昔の`ryunefields/ryunebrook`の音楽期待値と不自然な高速作業フレームのテストを新しい実装に合わせて修正し、見た目とテストのズレを補正。
- `package.json`：`npm run opening:play-evidence` を追加。実ブラウザの寄り道→通常のボス/王都通し→集計を順に実行する。

### 実際に確認したことと、していないこと

**確認済み（GitHub実ソース/V8）**：変更JS9ファイルの構文確認（エラー0）。`EVENT_DEFS`全87件が重複IDなし、追加された4イベントはすべて報告イベントを条件に持ち、台詞1行・報酬/ストーリー効果0。仕事ポーズはパン屋で時刻0・2000・2300・5000msに`0→1→3→0`を戻した。川の関数は近距離で有効、遠距離で停止。音楽は村・西畑・東小川の3地域に別々のプロファイルを返した。実ソースのCanvasコマンドを実行し、川面4個の矩形、報告後の川印3個の矩形を描画することを確認。

**未確認（証拠なし）**：`npm test`の全件PASS、Chromiumでの新規スクリーンショット、Windows Chrome/Edge・実機FPS、主観的なアート良否、音楽の長時間視聴評価、ボスの平均行動回数/HP消耗。実測JSONが未生成のため、敵の強さや回復量を根拠なしに変更していない。なお Chromium上の入力テストは自動化されたプレイヤーの操作であり、初見の人間によるゲームプレイではない。

## 有料RPGの最終受入基準

### A. ゲーム全体（S0）

- 正式な開始から正式なエンディングまで、デバッグ操作や直飛びなしで通せる。試作・文章による終了通知・UIだけの疑似分岐を完成エンディングとして数えない。
- 王国／帝国／灰冠の各正式ルートで選択内容、仲間、戦闘・会話、最終結果が整合し、メインStoryとSave schemaが矛盾しない。
- 目標8～12時間は**初見プレイ計測**によって確かめる。操作に迷って放置した時間や無駄な作業をプレイ時間の水増しに使わない。ゲーム性・物語密度・テンポの質を同時評価。
- 知らずに失敗し続けるバトル、進行不能、ロード復旧不能、UIが消える症状、バトルに4人が映らない等は重大不具合。未解消のS0/S1を抱えたまま有料販売しない。

### B. 美術と演出（S1）

- 48px原画と32px論理タイル、表示倍率、足裏基準線、建物との大きさ、場面ごとのレイヤーが一致。戦闘と街で四人の個性が分かる。
- 既存の画風・キャラ設定を勝手に変えず、アニメーションは場面に理由があるときだけ使う。足踏み、立ち絵の平行移動、異常な跳躍、過剰な光や画面揺れを拒否。
- 各主要都市・野外・屋内・戦闘での実キャプチャを比較。見た目の基準を通していない箇所は商用完成と呼ばない。
- BGM/SE/フォント/画像の権利と配布条件を確認した完成素材に置き換える。

### C. 操作、保存、配布（S0/S1）

- Windows Chrome/EdgeでZIP展開版の起動・戦闘・セーブ/ロード・再起動・ローディング・中断復旧を通す。単一HTMLも独立に検査。
- 旧v23保存データと主な旧バージョンのサンプルを実ロード。取得したアイテム、マップ、進行段階、編成・所持品が保全される。外部JSONによるPC移行も検証。
- キーボードとマウスで説明不要に操作できる。想定画面サイズでUIが見切れず、選択肢とアイテム説明が読める。
- エラーログと操作記録、実スクリーンショット、品質評価、未修正欠陥の一覧を同一コミットIDで揃える。

### D. 完成判定の切り分け

- **Code ready**: スタティック／Node検査のみ。販売不可。
- **Technical candidate**: Node + Playwright + ZIP/単一HTML +旧セーブ再生が同一SHAでPASS。まだ美術とシナリオ内容の承認は別。
- **Content complete**: 主要イベント・3ルート・正式結末・商用音源・アートが完成しており、骨組みや仮画面が残らない。
- **Release candidate**: Content complete かつ初見プレイ・ユーザー承認・動作検査を達成し、使用素材の権利証跡もある。
- **Paid release GO**: 上記に加えて配布ファイルのハッシュ固定と最終受け入れ。自動化の合格だけでは出せない。

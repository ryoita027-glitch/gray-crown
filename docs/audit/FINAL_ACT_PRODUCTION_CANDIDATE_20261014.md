# Gray Crown — 終章の実装と製品水準への到達監査 (2026-10-14)

## 現状の誠実な判定

**Paid-release / commercial-quality GO: NO.** ユーザーからの「本編未完成を完成させ、最新のゲームと競えるレベルまで磨く」という長期的制作目標は変えない。ただし GitHub 上の実装・静的検証と、「客観的に販売可能な製品であること」は区別する。

GitHub Issue #46 のGitHub Actionsランナーが未割当のまま失敗する問題により、直近統合HEADのフルCI合格やブラウザ録画を証明できていない。

## 見つかった具体的な終章の不足

既存 `js/data/maps.js` には `finalfield`, `imperialcamp`, `royalcamp` があり、`events.js` には王国/帝国/灰冠3ルートの仲間分岐、`battles.js` には各立場に対応した前哨戦（降伏可）がある。一方で、元の `showWorldSkeletonEnding()` は明示的に「未完成の演出プレビュー」と記されており、シオン／グランツとの会話後に**世界がどうなるかの因果、後半の実戦区間、正式エンディング美術・音楽**が不足している。

**結末を長文で水増しして、実装済みと呼ばない。** まず既存の前哨戦を通った後に、戦争中の誰を守るか・何を残すかという実際の決断を入れ、その選択が後日談の仮プレビューにも表れる部分を実装した。

## 今回の実装（新規内容）

### 1. プレイ可能な政治的判断 6パターン

`js/systems/events.js` の `FINAL_ACT_APPROACHES`, `runFinalActNegotiation()`。

| ルート | 戦闘後、プレイヤーが自分で選ぶ要求 | ゲームに記録する事実 |
|---|---|---|
| 王国 | 民間人の退路確保 | 避難する時間・道を求めた |
| 王国 | 両軍の命令・被害を記録 | 被害と責任の記録を求めた |
| 帝国 | 捕虜・負傷者を保護 | 国籍を問わない扱いを要求した |
| 帝国 | 追撃命令の撤回を求める | 伝令まで届く撤回要求を出した |
| 灰冠 | 守備兵に退く道を残す | 追撃を避ける意思を述べた |
| 灰冠 | 服従を命じる | 命令は出したが、受諾は未確定 |

これらは`events.choices['route.final.'+route]`に保存する。各ルートで仲間の立場選択があり、戦闘チェックポイントがクリアされていることが前提。選択が済む前に勝手に一方へ確定しない。重複会話・重複日誌も生じない。誰かが要求を受け入れた／国家が降伏したという**新しい確定設定は書かない**。

灰冠はこれまでの非道徳的行為が取り消されたことにしない。王国/帝国ルートの4人の保存済み編成も変更しない。灰冠の別離と既存ソロ/2人パーティーも維持。

### 2. エピローグ候補への反映

`js/systems/movement.js`: 先行する灰冠関所戦後もNPCの選択会話を経る。既存の3ルート・6立場別プレビューには**最後に示した条件**の欄を追加。ただし`未完成`表記、王国・帝国の仮結末、`worldSkeletonCleared`の性質は今の時点でそのまま。ストーリーの正式解決を偽装しない。

### 3. 区間別の音色・旋律候補

`js/systems/audio.js`, `js/systems/commercial_soundscape.js`: 共通`travel`に混ざっていた後半区間を、国境・帝国の生活圏・聖域・帰還路・最終前線・帝国本陣・王国本陣へ分類。16拍を使った小さな静的旋律候補にし、地理と陣営の区別を付ける。既存序盤曲／戦闘曲のロジックは維持。音量は低め。

これは **WebAudio合成による仮音楽**。正式な作編曲、音楽的ドラマ、マスタリング、音色設計、権利と配信条件に関する商用品質合格は未判定。合成音があることを完成OSTと呼ばない。

### 4. バランスを推測で改変しないための計測

`js/systems/battle.js` の transient `state.battle.metrics` は以下の指標を内部ログ `GC.Log` へ一時記録する。

- 戦闘ID・マップ・決着（勝利/降伏/全滅）
- ターン数・経過ミリ秒・有効なスキル/道具使用回数
- 敵からの攻撃回数・合計被ダメージ
- 初期HP/MP合計・終了時のHP/MP合計・戦闘に参加した主人公

デバッグコマンド／外部送信／個人情報収集／セーブ形式の変更はない。ゲームの実戦ログは最大300件の既存ローカル履歴に従う。降伏のために士気を人工的に1へ変えた **seeded Chromium** の戦闘記録を、自然なプレイヤーの難易度データとして使わない。通常キーボード操作の`browser_vertical_slice_e2e_test.py`のみ、実バトルの`local_balance`を測定証拠へ出力する。

**記録を追加しただけで難易度が改善したとは言わない。** 敵HP/攻撃力や回復量を今適当に上書きしても、遅い・退屈・易しすぎる・詰みなどの原因は分からない。後日の本物の測定で調整する。

## 有料製品へのS0/S1残課題

**S0** 全章をリアルに歩いて遊べること：Story 00–19以降に残る説明だけのマップ、弱いイベント導線、短い仮本編、正式3ルートの帰結と決着、イベントの順序と不可逆性。キングダム/エンパイア/灰冠でそれぞれ最終区間の移動・対話・最終戦・退却・救護・復興後の結果を因果で描く。勝利/敗北/降伏や仲間の選択が後で矛盾しない。

**S0** セーブ/旧互換と配布：`main`との差分を統合審査。経路途中・戦闘直前直後・別ルート再開を実画面で確認。Windows Chrome/Edge、ZIP版/単一HTML、ファイル移行、画面幅390px～デスクトップを試す。

**S1** 美術・キャラクター：4人とNPCのPixel Actingの実ブラウザ比較（48px→44px描画、足裏揃い、倒れた/歩行/驚き/会話）、建築とキャラの縮尺、遠景、街/野外/室内、戦闘UIを1つずつ評価。未確定紋章・装束・シオン王冠は勝手に正史化しない。仮のドット絵タイルや汎用NPCで美術完成を名乗らない。

**S1** 音楽：地域と3陣営に一貫した主題・編曲・楽器構成・効果音・無音の使い方を設計、完成音源の配布権を確認。現行は仮音源。

**S1** バランス：全編正常操作の初見プレイヤーの周回。各章の平均ターン、敵の撃破時間・全滅率・生存HP/MP・道具使用・強制稼ぎ・選択肢の分かりにくさ・周回時の疲労を計測して変更。ゲーム尺8～12時間を実測。長い敵HPや冗長な台詞で尺を水増ししない。

## 厳格な判定基準

- **Prototype feature implemented** ≠ commercial quality.
- **Node static/source V8 PASS** ≠ Chromium/Windows gameplay PASS.
- **Seeded route test** ≠ uninterrupted New Game → final credits playthrough.
- **Procedural melody** ≠ licensed/mastered finished score.
- **Route teaser with unfinished label** ≠ complete ending.
- **8～12時間という目標** ≠ 実際に遊べた時間。

同一HEADで `npm run product:local-quality` と正式実機評価を終え、コンテンツの未完成箇所と S0/S1不具合がなくなり、ユーザーから正式採用の判断を受けるまで、このPRはDraft・`main`未変更・有料リリース不可とする。

# Gray Crown — プレイヤー視点での序盤美術評価（2026-10-14）

## 結論：不合格のまま。改善候補を検証中

ユーザーからの「王都が戻って見える」「村人が全然違わない」「マップが増えただけで面白みがない」「安っぽい」は正当な製品評価。従来の **37形状 / 371描画矩形 / 新規マップ数 / テスト本数** を完成判断に使わない。**人が通常のゲーム表示で違いを感じることが必須**。

旧版の実プレイスクリーンショット（2026-10-09）の目視:
- 町の建物は箱が等間隔、壁/屋根/入口の見え方が似ている。町並みより盤面のパーツ配置に見える。
- NPCが遠景に点在し、一見して人柄・役割の差が弱い。主人公4人の表情や関係と比較すると住民の魅力が弱い。
- 「家の前に小さい四角を追加する」といった装飾では変化が見つけにくい。
- 序盤の西畑・小川の任意会話だけでは、探索の面白さを十分に生み出せていない。
- 古い画像は現在のPR77 HEADのスクリーンショットではない。**現在の実ゲーム画面に対する合格判定には使わない。**

## このブランチの実改修：9人の手描き32pxスプライト

従来の `OpeningPixelAssets.person()` 共通素体から完全に分離した **32×32px、4方向×9人の専用PNG** `assets/npc/featured_residents_v1.png` を作成。
- リュネ村: エダ（大きな白いパン帽、パン籠）、ボル（広い麦わら帽と農具）、ナナ（白髪・長い肩掛け・杖）、村長（整えた白髪・帳簿・長い上着）、王国使者（旅外套と巻紙）、レン（子どもの頭身と稽古木剣）
- 王都: 花売り（編んだ髪と花束）、新兵（かぶと/軍装と槍）、グランツ（大きな肩の軍装と濃色外套）

**9名のみが改修対象。** 37人を描き直したという主張はしない。`js/render/opening_pixel_assets.js` の `tryFeatured()` がこれらの既製プロファイル代わりに、名前と向きで4方向の元画像を等倍32pxで描画する。PNGが読み込めない場合は既存のゲーム用スプライトへ安全にフォールバックする。元の主人公4人48px素材、NPC座標、当たり判定、全Story、Save schema23、ゲームバランスは変更しない。

専用素材は Photoshop 等の外部画像を流用しておらず、画素を手で指定した独自のドット原画。33色前後へ圧縮しても透明背景と輪郭を維持（PNGサイズ小）。「9人の違いを見つけるためにラベルを読まなくて済むか」が承認基準。

## 私自身の美術査定：不合格箇所も明記

**仮のデザイン評価（等倍と拡大のPNGを目視）**
- **改善の候補**: パン屋の白い大きな帽子、農夫の麦わら帽、老婆の幅広ショール、新兵の兜/槍、花売りの髪と花束は、従来の「同じ箱の色違い」よりシルエットで識別しやすい。
- **まだ安っぽい点**: 正面の目・口・頭部の表情差はなお小さい。方向転換には対応したが、自然な歩行・手作業・聞く/話す演技の専用フレームは**まだない**。新しい画像は1人1体の固定ポーズで、全身の魅力を完成したわけではない。
- **ゲーム画面全体の評価**: 王都の構造・建物・導線はPR77から変更していない。街全体はまだ安っぽいと判定する。ここを「9人の画像」で隠さない。
- **採用条件**: 9人が実際のリュネ/王都で背景に埋もれず、服/顔/足元が崩れず、4方向で瞬間的に別人に見えないこと。主人公4人と並べても頭身差が自然であること。台詞・役割と外観が一致すること。

## 今回までの実測
- 実PNGは 288×128px、9人×4方向。V8でゲーム用レンダラを実行し **36回の人物+方向指定描画、1回の画像ロード、画像準備後の再描画1回**を確認。
- `tests/featured_resident_player_visual.test.js`：ファイルのPNG署名とサイズ、人物名から画像座標・向きの対応、旧スプライトへのフォールバックを検査するコード3件を追加。全Nodeテストは未実行。
- `tests/browser_town_visual_quality_e2e.py`: 実PNGの `featuredStatus().ready` を待つよう変更。一般的な代替NPCのまま画面撮影を行った結果を**合格にしない**。現在HEADの実Chromiumテスト未実行。
- ローカルの画像プレビュー `gray_crown_named_residents_preview.png` を作成。これは **PNGの等倍表示・拡大表示サンプル**であり、ゲーム内の実プレイ画面ではない。手元のChromium PNG描画スモークは実行環境でタイムアウトした。

## 次の制作上の優先順位
1. これら9人を等倍で現行ゲーム画面に置き、拡大時と異なる魅力/背景に沈まないかを目視検証。良くない9人は描き直す。
2. 特に村長・使者・レン・グランツ・花売りの表情、髪の立体感、身体の釣り合いを仕上げる。無闇にNPCを増やさない。
3. リュネ村と王都の「建築本体」の面積・シルエットと通りごとの個性を再設計。広場の箱を増やすだけでは不合格。
4. 西畑・小川での移動・判断・結果の具体的な楽しさが実測で不十分なら、区間を縮めることも含めて再設計。プレイ時間を水増ししない。
5. 同一SHAの本物のゲームスクリーンショット（現行と旧版）および初見プレイ評価で合否判定。合格するまでDraft。

**一般的な方針**：改修実装 = 完成ではない。実際に遊んだ人が「確かに良くなった」と判断するまでは、数的指標や大量の報告書より**実画面・プレイ体験**を優先する。

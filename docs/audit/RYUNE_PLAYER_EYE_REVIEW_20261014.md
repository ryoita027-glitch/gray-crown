# Gray Crown — 序盤の人間目線での美術・遊び審査（2026-10-14）

## 品質判定

**視覚品質：HOLD（未合格）／序盤の小さな遊び：実装候補／商用製品：NO GO。**

PR #77の試遊版に対するプレイヤー本人の評価は「王都が戻ったように感じる」「村人が変わって見えない」「寄り道がつまらない」「全体が安っぽい」。この事実を発見数・ファイル変更数・Canvas矩形数によって覆さない。PR #77は拒否された美術プロトタイプとして扱い、新しい候補は別Draftで制作する。

### 見た目で実際に比較した内容

2026-10-14、実 `js/render/opening_pixel_assets.js` から `OpeningPixelAssets.distinctRyune()` を取り出し、パン屋エダ／農夫ボル／村長／帰還兵／王国使者／レン／ルル／王都市場商人／花売り／新兵／係官／グランツの **12人を同じ背景・同じ前向き姿勢で実ピクセル描画し、拡大して目視**した。

**第一評価：不合格。** 帽子・服の差はあっても、ほぼ全員の顔は同じ角ばった肌色の四角と同じ2ドットの目。名前と色を除くと魅力に乏しいと判断。

**修正：** 頭部の角の陰影、眉／目の高さ／口の表情、仕事に即した手荷物、左向きの顔の見え方、髪の重なりを調整した。その後もう一度同じ12人の並びで目視。形と表情の違いは改善したが、顔と胴体の箱型感はなお残る。**2回目も商用品質合格とは判断しない。**

### 実装の対象と上限

| 区分 | 今回の実変更 | 実際に見える可能性／未達 |
|---|---|---|
| NPC | `OpeningPixelAssets` に12人の **共通 `person()` 不使用の個別ドット絵描画**。4方向×4フレームの既存atlasへ入る | 12人の作業・会話・歩行アニメがすべて完成したわけではない。顔の魅力はさらに制作が必要 |
| 村の中心 | 井戸の灰色の箱を、石組み・木の庇・桶を含む32pxの専用シルエットに描き替え | 建築全体の密度・遠景・建物の立体感はまだ足りない |
| 小川の探索 | 西畑と小川を任意調査して農夫へ報告 **した後**、元の石積みで選択が可能。岸から届く小枝を片づける／水位を測る／何もせず戻る | 新マップを追加せず選択が地面に残る。プレイヤーが本当に面白いと感じたかは未実測 |
| 会話の反応 | 結果に応じて農夫が1回だけ返答、`events.choices['ryune.worksite.action']` と受領確認を schema 23 で維持 | 無限会話・重複報酬・メインStoryの進行条件は追加しない |
| 屋外の反映 | 小川の石積みのそばに、片づけた小枝か水位印が別のドット形で残る | 全水路が修復されたふりをしない。水の流れと衝突は既存通り |

### 人間が審査する「合格条件」

1. **1倍表示（32px）で無名の住民12人を見せ、**帽子や色だけでなく髪、頭身、肩、服裾、表情を手がかりに区別できるか。ドット数の差で合格にしない。
2. **同じ人物が正面と横を向いたとき**髪の質量／輪郭／衣装がつながっているか。横向きの単なる前向き顔のコピーは禁止。
3. **村に立つ主人公4人との比較**で足が浮かない・道具が頭を隠さない・32px NPCが消えない・住民を幼児と誤認しない。
4. **村井戸の画面で足を止める価値**があるか。建物は箱に見えないか。広場の芝の平坦さと住宅の間隔に違和感がないか。
5. **小川へ歩く時間に見合う体験**があるか。選んだことが地形と返答の両方に残るか。つまらない場合は寄り道を縮小する。
6. **王都を見て前の版とほぼ同じなら王都美術は不合格。** 今回は王都マップの骨格自体を改修していない。PR #77の外壁矩形追加だけで達成したとは呼ばない。
7. 390px/デスクトップの実Chromium画面、1x/4xの並び、会話時の動作を見て、人間が**良くなった／まだ安っぽい**と明示評価する。自動テスト成功は品質審査に代わらない。

## 実装に伴う検証

- `tests/ryune_player_eye_opening.test.js`：任意小川選択・何もしない／再挑戦・一度限りの農夫返答・絵の2分岐・旧v23セーブ・12人独立描画・4方向の形状・アトラス境界（32px内）を検査する **7件のNodeテストを追加**。
- `tests/browser_ryune_outskirts_e2e_test.py`：新規ゲームから村→西畑→小川→農夫への報告→再訪、**実際の石積みに通常キーで話しかけ、画面選択で水位を測り、絵の違い・農夫・セーブ23を確認**する想定（8枚撮影）。DEVフラグの注入なし。
- `tests/browser_town_visual_quality_e2e.py`：本物のNPCアトラスを正面・左向き、実寸32pxと4倍、計4枚新規撮影（町/屋内12枚と合計16枚）。撮影されたことは品質承認ではないのでマニフェストのstatusは `CAPTURED_PENDING_HUMAN_ART_REVIEW` とする。
- `js/systems/events.js` で `runTriggeredEvent` から新イベントを実際に処理した場合には常に `true` を返す。未処理扱いによる既存フォールバック会話の上書きを防止。

### この環境で実施できた検査と未実施の検査

**実施：** 現行GitHubの実JSをV8評価した小川イベントの選択（3つの選択肢、意思決定記録、農夫の一度の返答、所持品／Story段階不変）。12人の独立ピクセル描画を実行、正面と左向きの両方でキャラごとの形状差を確認し、32pxアトラスからの矩形はみ出しがないことをチェック。実際のラスタ画像を生成して目で確認し、視覚合格は保留とした。

**未実施：** GitHub最新同一SHAにおける `npm test`、Playwright実ブラウザの一連の操作・実ゲームの環境との重ね合わせ・Windowsと390px実機・人間の初見プレイ。実画面の継続改善はこれらを行ってから採否判定する。完成した人物全員の高品質な手作りスプライト素材、魅力を感じられる王都の立体街区、正式な全ストーリー/音楽もなお制作対象。

**次の開発優先順位:** 12人の顔の魅力をさらに上げる → 主人公とNPCを同じ村の画面で比較 → 住宅の屋根／王都市場の構造を実画面から抜本変更 → 任意小川の面白さを実測して維持/縮小を判断。ファイル数やイベント数を増やしただけでは完成としない。

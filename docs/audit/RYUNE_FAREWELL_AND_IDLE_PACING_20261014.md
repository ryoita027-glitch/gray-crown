## 1. 元の村と家で四人の性格が分かる会話

王国使者の `alpha.village.appointment` を本人たちが受け入れた **Story stage `01_appointed`** の間だけ、既存NPCの最初の任意再会話に3行の別れを追加した。

| 既存NPC / 場所 | 表現する感情・性格 | 動作条件 |
|---|---|---|
| 弟リオ / カレンの家 | カレンが兄弟の身近な井戸仕事を気遣う、昔からの軽い冗談 | 任命後、本人に話しかけた時だけ |
| レン / リュネ村 | トリトンの剣の稽古と身近な関係、勇ましさより日常の約束 | 同上 |
| テオ / 孤児院 | ソフィが薬の扱いを具体的に教える、無理な約束を増やさない | 同上 |
| マーガレットの母 / 村長宅 | 本・地図・筆記具に表れるマーガレットらしさと親子関係 | 同上 |

データは `js/data/events.js` の4イベントに収め、各 `effects` は該当 `completeEvent` **1つだけ**。金銭・アイテム・経験値・マップ移動・パーティー・メインStory・目的地は変更しない。再訪時は元の `inlineNpcEvent` をそのまま使う。実際に北門から出るだけなら話しかける必要はない。

**意図的に行わなかったこと**: 全員の別れを強制するムービー、無理な「泣かせ」、親を動かすためのランダム歩行、帰還確約を国王や帝国の確定設定にすること、村の規模を増やすだけの空地追加。

## 2. 発見表示の圧迫を防ぐ

`GC.CommercialDiscovery.progress('village')` はこれまで、プレイヤーが西畑と東の小川を一切見ていなくても「畑と小川の見回りを報告」を未達一覧に表示していた。このままだと寄り道が強制ToDoに見える。

改修後は以下の扱いにした。

- 調査前、あるいは畑だけ調べた場合: 村の寄り道一覧は本来の孤児院薬草相談のみ。
- **西畑と小川を両方実際に調査した後**: 初めて村の農夫へ報告できることを任意の発見として表示。
- 報告後: 発見済みの項目として残る。元の農夫イベントや報酬の条件自体は変更しない。
- ツールチップも「まだ調べられること」ではなく「気が向いたら調べられる場所」とする。メインの王国使者マーカーには影響しない。

## 3. アニメーションの質とフル画面Canvas再描画の節約

PR #74の村人アニメーションは仕事の姿勢が変わるのが8～11秒周期なのに、近くに立っているだけでCanvasを**200msごとに全面再描画**していた。東小川の水面も実際には700msおきにしか絵が変わらない。不要な再描画はPC・低電力ノート・スマホで消費やカクつきの原因になる。

- `OpeningWorldLife.nextWorkFrameDelay(map,x,y,npcs,now)`: 実際に見えている作業員の姿勢が変わる次の時点へタイマーを合わせる。パン屋の例: 時刻 `0ms → 1565ms`, `1565ms → 500ms`, `2065ms → 500ms`, `2565ms → 7000ms`。静止7秒間はそのための再描画をしない。
- `RyuneOutskirts.nextWaterFrameDelay(...)`: 水面にプレイヤーが近く、OSがReduced Motionでない場合にだけ、次の700ms単位の整数ピクセル変化へ再描画を合わせる。
- `js/render/world.js`: 仕事と水の次の変化の**より早い方**で1回だけ描画。歩行やキャラ演技中は従来のRAFを優先し、古いアイドルタイマーをキャンセルする。
- 通常の歩行フレーム、既存の主人公アニメーション、通行可否、32pxタイル／48px主人公シート、楽曲、NPC座標には変更なし。

**観察すべきリスク**: 背景アニメーションの滑らかさ、ブラウザが背面に移動した後のタイマー再開、ほかの動作で持続しているRAFとの二重描画、バッテリー負荷。数値から速度改善を主張するのは実測後に限定する。

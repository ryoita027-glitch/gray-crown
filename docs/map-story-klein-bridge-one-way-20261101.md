## 実装した縦切り
1. 橋上のクラインテッドに接触すると、カレンが「渡れば砦に戻れなくなるかもしれない」と短く警告。二択「四将と向き合い、橋を渡る／砦へ戻って準備する」。
2. 引き返しを選んでも進行フラグを立てず、砦で休息・探索できる。再接触で同じ選択が可能。
3. 進む場合は既存の15行の会話・橋崩落シーンを省略せずに再生。最終台詞を読み終えた時だけ `metKlein` / `kleinBattleDone` を立て、既存の `enterEmpireVillage()` へ接続。帝国村への移動と「橋が落ちて帰れない」既存の南出口応答を一致させる。
4. 新しい報酬、強制寄り道、マップ面積、イベントID、セーブ項目を増やさない。初見のプレイヤーは「戻れないかもしれない」を理解してから選べ、崩落後に砦へ歩いて戻る矛盾を経験しなくなる。

# NPCの生活アニメーション実装仕様書 v1

**アニメーションは演技であり、背景を動かす装飾ではない。**

## ポーズの5区分と実装の正確な区別
| 種類 | 現行 | 合格条件 |
|---|---|---|
| 待機 | 既存32px atlasの静止フレーム | 足裏・向きが自然、呼吸で上下し続けない |
| 歩行 | 方向4面／フレームの原型あり。常時徘徊は未導入 | 本当に座標が移る時のみ歩行。障害物と重ならず接地 |
| 作業 | 一部の名付き作業員に短い `workPhase` | 仕事対象・道具と同期。無目的な腕振りは禁止 |
| 振り向き | 近づいたプレイヤーへの方向転換表示あり | NPCが相手を見ている。遠方では振り向かない |
| 会話 | 台詞表示に対する共通NPC動作は限定的 | 聞き手は静かに待ち、話者だけ場面に合った短い所作 |

## 人物×場所の動作理由
- 畑の作業員：耕した列の近くで用具を見る。小川見回り人：川を眺める基本静止。
- エダ：焼き物の配列を整える、手は商品の高さだけ上下。村長：帳簿確認は村長宅や村務付近だけ。
- 孤児院のマルタ：子どもたちの様子を見守り、無関係な抱擁や過剰な笑顔を禁止。
- 子ども：遊び道具、短いしゃがみは動線が確保できたときに限る。常時走らせない。
- トリトン父：稽古場面だけ姿勢を整える。武器を振り回す通常会話にはしない。
- 王都鍛冶師：鍛冶場に固定した手作業と鍛冶音、歩行と混用しない。
- 配給待ちの親：荷物を少し持ち直す程度、過剰な泣き/手振りは不要。
- 市場の行商人：商品配置の小さな動き。衛兵：警戒を示す静止と近距離の振り向き。

## 技術
- 作業姿勢は既存 `OpeningWorldLife.workPhase(id,now)` の8〜11秒周期、短い2姿勢だけに留める。
- この版の追加実装：`OpeningWorldLife.workplace()` が村長宅の書記、王都の宿の女将、鍛冶師・見習いの4人に **実際の帳簿・鍵/伝票・工具** を持たせ、アトラスの腕と同じ短い拍で動かす。無関係なNPCには発動しない。
- 見た目が変わる瞬間にだけ描画を予定する `nextWorkFrameDelay()` / `nextWaterFrameDelay()` を維持。
- ブラウザの `prefers-reduced-motion` で停止。
- 方向 `down/left/right/up` と実座標を分離。絵だけ先に走らせると足元が滑るので厳禁。
- 各新作業は **実在する道具・位置・理由・実画面比較** の4点が揃うまで自動で付与しない。

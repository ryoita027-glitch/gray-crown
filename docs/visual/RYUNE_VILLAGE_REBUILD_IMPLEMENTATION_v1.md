# リュネ村 高品質化の実装指示書 v1

**変更済み: 指定の一部を実コード化。** 続きの制作判断と QA を含む。既存の任命・北門・寄り道は必ず保全。

## タイル設計（原点は左上、x=0..23、y=0..14）
- 中心の井戸 `[12,9]` と任命位置 `[12,6]` を絶対移動しない。北出口 `[11/12,0]` を維持。
- 既存家区画：カレン家 `[3,2]`、孤児院 `[18,2]`、村長宅 `[3,9]`、東の民家 `[18,9]`。
- 西の畑 `x0,y8` と東の小川 `x23,y8` は **任意の寄り道**。新たな必須条件・戻れない片道を作らない。
- `makeVillageTilesV2()`：第8行に東西の踏み固めた徒歩道、第12行には住戸脇をつなぐ短い横道。H建物、T境界、NPC・オブジェクトは保持。
- `RyuneEnvironment.districtDetails()`：村務の書類、井戸側の足跡、共同養育の玩具、畑の植生を既存位置に固定表示。
- 井戸広場には生活の静けさを残す。露店・荷物・ベンチを全部同じ場所へ集中しない。

## 施設の外観・内装
- カレン家：高めの木屋根、家族の人数を感じる食器と小さな靴、日常の薪。
- 孤児院：横へ広い共同施設、手入れされた長椅子、共用寝具・玩具と食品備蓄。
- 村長宅：出窓・記録棚・机の資料。宗教や国王の紋章を新作しない。
- 東の民家：屋根の補修、小さな薬草・裁縫道具、兵士不在を表す寝具と手紙。帰還の結末は断定しない。

## 描画の扱い
- 住民は背景の後に描く。衝突に使う `maps.village` には**装飾用の見えない壁を追加しない**。
- 経過時間で村を不自然に昼→夕方へ切り替えない。夕景は別の専用イベントと正史の時刻が決まってから実装する。
- フレーム固定の足底を維持し、住民ごとに意味がない歩行アニメは導入しない。
- 児童が歩く経路、洗濯・掃除の長時間動作は **通行安全・家庭行動との整合・実画面検証後** の継続課題。

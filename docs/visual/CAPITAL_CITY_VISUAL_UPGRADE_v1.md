# 王都アルディナ 高品質化の実装指示書 v1

## 地区の視覚的階層
王城前（北）：高い壁・明るい石・儀礼用の見晴らし。軍務（東）：整った灰青石、物資棚、守備用の胸壁。市場（西）：布の軒・店先の実用品・不均一な中古荷箱。職人街（南）：修理工房・炉の使用感・低い倉庫。

- `js/data/maps.js` の原地形を保持。王都はメインストーリーと各所のドア・配給が強くつながっており、むやみに位置を再配置しない。
- `js/render/capital_environment.js` の `facades` 8棟を機能別の外形へ変更：市場家・軍務棟・官庁側の屋根・職人工房を混ぜない。
- 主要地点: 城前 `[12,4]`、市場 `[5,9]`、軍務街 `[18,9]`。地面の摩耗や縁石を3区画で変える。
- 既存の店・宿・兵装店のドアと相互作用座標を変更しない。プレイヤーが実際に入れない偽の扉や「押せそうな」新規台は作らない。
- NPC: 王都係官、商人、花売り、新兵、配給待ちの親、鍛冶師、旅籠女将。衣装の層と持ち物を職業に一致させる。

## やらないこと
- 人数を10人から100人へ水増しするだけの群衆。
- 全員に同じ待機足踏みや全方向ランダム歩行。
- 王国正式旗章や宗教マークの勝手な確定。
- 町全体に粒子/映画調の光を載せてドット絵をぼかす。

## 受入基準
- 既存の7NPCと8つのインタラクト対象が正しい場所へ残る。
- 西市場の棚/布と東軍務街の保管箱が視覚的に区別できる。
- 店舗へ至る実歩行ルートが維持される。
- **商用美術のGOは実Chromiumでの100%/150%/モバイル画面の比較・実測後**。今回の版はそこまで未承認。

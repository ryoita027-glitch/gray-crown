# Gray Crown｜村人・街人アート基準書 v1

**状態：コード候補実装済み／実ブラウザ美術承認は保留。** 「安っぽさ」を消すことが目的であり、色数やNPC頭数をむやみに増やさない。改変範囲は住民の役割・輪郭・道具・素材感。主人公4人の承認済み48px PNGは上書きしない。

## 技術制約
- ゲーム論理マップ24×15・32pxタイル。住民は32×32セル、4方向×4フレームの既存 `OpeningPixelAssets` atlas。
- 顔・髪・服・足の優先順位：**姿勢と体格 → 髪外形 → 上着形 → 役割道具 → 目鼻の少数ドット → 色**。
- 足底は既存の行末に揃える。歩いていないNPCを4フレームで足踏みさせない。既存の `workPhase` は実際に作業している住民の短い手の動き専用。
- 輪郭は暗い色で明確に、影面は基本2段。ぼかし、アンチエイリアス、レンズフレア、光粒子、外部から借りた絵柄の混合は禁止。
- 鮮やかな赤/青の衣装を一般住民に乱用せず、勇者4人の識別性を守る。
- 不定の宗教・国章・正式軍階級章・勇者標章・帝国紋章は **勝手に描かない**。

## ロール別・実際の輪郭条件
| 役割 | まず見る特徴 | 生地 / 使用感 | 道具・腕の動作 |
|---|---|---|---|
| 農民 | 帽子、短い上着、巻き袖、作業のための安定した姿勢 | 土・色褪せた麻布 | 鍬・測量棒を扱う手。足は静止 |
| 生活者・家族 | 前掛け、縫い目、羽織、子を世話する体勢 | 家の負担に応じた補修跡 | 洗濯物、食器、荷物。ただしどこでも突然持たせない |
| 子ども | 小さな頭身・丈の短い服・独自の髪外形 | もらい物や簡素な布 | おもちゃ、稽古棒、学用品。危険な走行はシーン限定 |
| 高齢者 | 腰回りの厚い衣類、肩掛け、頭髪形 | 長く着ている補修布 | 杖は現実に必要な人物にだけ |
| 商人 | 裾の幅、財布や小荷物、実際の店舗との距離 | 汚れ具合と仕立ての商圏差 | 荷箱・値札・梱包 |
| 宿屋 | 前掛け、鍵・帳簿、腕の使い方 | 水気に耐える仕事着 | 宿泊帳、器の片づけ |

| 旅人 | 肩鞄・外套・歩き慣れた靴 | 砂埃・風雨の劣化 | 荷物を持ち直す短い動作 |

## 都市文化・階層
リュネ：天然の木・粗い石、繕った服と控えめな装飾。貧しさを全員に同じ穴あき服で記号化しない。農夫と書記が同じ清潔度になるのも不可。村長宅と孤児院は手入れや整頓の理由が異なる。

王都アルディナ：制服・職業服は縫い目や襟に規律。軍務街の装備は丈夫、市場は機動性と汚れ、城前の係官は端正。富裕層・低所得者の差は**服装・姿勢・荷の状態**で表し、色だけで決めない。

## 現行コードと残課題
- `js/render/opening_pixel_assets.js`：既存の匿名汎用輪郭に加え、命名された住民ごとの `identities` と `signature()` を導入。子ども、家族、農夫、書記、衛兵、鍛冶師、女将など、形と小物を分ける。
- `js/render/opening_worldlife.js`：パン屋・農夫などの **短い仕事姿勢** を維持。
- **未完成**：全住民ごとの独立した自然な歩行・会話・振り向き・作業の5種類の専用絵。現在のatlasは4方向×4フレームで、キャラ固有の完成アニメーション一式ではない。実画面を確認し、目立つ10名から段階的に専用フレームを増やす。
- **承認検査**：12名を輪郭シルエットのみ（色なし）で並べ、少なくとも9つの独立した形が分かるか。32px等倍と2倍、主人公48px描画との縮尺、顔欠損、足元、歩行と会話中のフレームを確認。

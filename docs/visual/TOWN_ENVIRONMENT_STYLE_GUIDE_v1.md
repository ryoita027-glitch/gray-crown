# Gray Crown｜町・村の環境美術基準書 v1

**視覚上の生活動線が最優先。** 地形と衝突、イベントは `js/data/maps.js` が唯一の正規ソース。背景アートは当たり判定やメインStoryを変えない。

## 3層の画面設計
1. **遠景・建物:** 建築の屋根形、石積み、畑区画。質量を見せつつ空から光粒子を降らせない。
2. **生活中景:** 人の導線を示す敷石、薪、物干し、修繕跡、荷物。家の入口がどこか分かる。
3. **近景・主人公:** 重要NPCと主人公が一目で識別できる余白。20〜40pxの顔を小物で覆わない。

パレット基準：村は木・土・苔と温かい石材、王都は古い白石・赤茶の市場布・青灰の軍務区。芝生全域のランダム花畑や光るUI風の看板を置かない。すべて手描き整数ピクセル、アンチエイリアスなし。

## リュネ村の町内構造
- 中心：共同井戸 `[12,9]`、北→南の本路、王国使者 `[12,6]`、北門 `[11,0]`。
- 西：生産・農作業。既存の西畑の出口 `[0,8]`、歩いて分かる小道と農夫ボル。無駄な広大農地は作らない。
- 北東：共同養育の孤児院、生活路と子どもの活動地点。物干しは既存住民にかぶせない。
- 南西：村長宅と文書・記録の場所。
- 南東：兵士の帰りを待つ家。日常の痕跡は軍の帰還を確約するものではない。
- 東：小川へ通じる別の生活路 `[23,8]`。遊びの道に危険な近道を偽装しない。

`makeVillageTilesV2` は元のH/Tの障害物・全NPC・全オブジェクト座標と Story北出口を保持し、西東の足道と南の短い家路を土Pの歩行タイルで明確化。中心の導線は引き伸ばしていない。

## 王都アルディナの地区差
- **王城前:** 浅い白石・高い壁・広いテラス。行政の秩序と人が小さく感じるスケール。
- **西市場:** 布屋根・粗めの石舗装・荷の積み下ろし・近くに住民。値段の高さや配給の不安も、店先の違いとして読む。
- **南の職人街:** 補修木材、仕事場の棚、武具工房の入り口。
- **東の軍務街:** 規則的な窓、高い腰壁、頑丈な供給箱、配給と軍需品の対比。

今回 `CapitalEnvironment.facades` で8つの**既存H建築タイル上にだけ**専用意匠を追加。新しい通行不能セルも偽装の扉も増やさない。

## アセット承認条件
- 1280px以上と390pxの本物のブラウザ画面で住民・主役の顔と出口を見失わない。
- 色相を落とした「シルエット比較」でも村/王都の区別がつき、同地区の建物8棟も全部同じ箱には見えない。
- 既存の北門、西畑、小川、各家・宿・兵装店入口がすべて隣接して操作できる。
- 既存と変更後の同一地点のスクリーンショットを保存。評価していないものは **候補、商用品質未承認**。

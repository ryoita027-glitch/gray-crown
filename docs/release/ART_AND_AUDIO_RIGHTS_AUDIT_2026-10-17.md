## ランタイム側の確認

- `js/systems/audio.js` は AudioContext のオシレーター・GainNode を用いた合成音の実装。既存コードだけを見た限り外部BGM/SEファイルをロードしていない。ただし作曲・著作・効果音表現の完成品質は別判定。
- `css/game.css` は Segoe UI / Yu Gothic UI / Georgia / Yu Mincho / system-ui 等のシステムフォントを参照。リポジトリ内で独立したフォントファイルや@importによる外部フォントを確認していない。Windowsや他OSで代替書体となるため、表示試験が必要。
- HTML・JS・CSS・ドット絵を同梱する前提だが、リポジトリのツリー内にLICENSE/credits/attribution/rights台帳を確認できなかった。未確認だから違反と断定しないが、販売承認の証拠不足とする。

## 販売前の必須確認項目

1. PNG43点とゲーム内にプログラム描画される背景・UIについて、制作主体、元画像・参考素材・生成AIの利用有無、共同制作/委託の有無、第三者素材の使用条件を証拠付きで記録。
2. 配布形態（ZIP/単一HTML/販売ストア）で商用再配布ができるか、必要なクレジット記載と禁止事項を確認。
3. フォントの各OSでの表示と、必要なら商用ライセンスを確認したフォントだけを同梱。
4. BGM・SEに追加素材を使うなら元音源ごとに出所、ライセンス全文、購入・許諾証拠、クレジット要件を記録。
5. 公開前に第三者の著作物・商標・既存作品との混同リスクを確認し、許諾を確認できない画像・音は販売パッケージから外す。

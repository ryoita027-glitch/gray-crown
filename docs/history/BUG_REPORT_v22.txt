- 原因: say(speaker,text,choices,next)のsignatureを誤認。
- 修正: travelSceneはsay(..., [], finish)を使用。
- Regression: 既存Ash Road Node/E2Eを再実行。

2. Frontier MAP_FEATURESでvanguardCaptain NPCをoptional objectへ誤登録
- 再現: Validation FEATURE_BAD_OBJECT。
- 修正: NPCをoptional object一覧から除外。
- Regression: Validation 0 hard errors。

3. Frontierの旧imperative処理と新data-driven処理が共存すると二重発火する危険
- 修正: systems/events.jsから今回使用するfrontierOfficer/frontierMedic/vanguardCaptain/Frontier object処理を撤去しdata/events.jsへ一本化。battle.jsのvanguardCaptain専用戦後処理も撤去。

4. v21では灰の街道北端が区間終了メッセージのみでセラドへ遷移しなかった

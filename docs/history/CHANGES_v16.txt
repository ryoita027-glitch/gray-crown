Playable Alpha v16

【Game Feel戦闘】
- 最初の灰牙狼戦を1体戦へ変更。
- 戦闘背景上に敵グラフィック、HP、士気を配置。
- 攻撃の踏み込み、敵ヒット揺れ、ヒット停止、ダメージポップを追加。
- Web Audioによる仮SEを追加。

【士気 / 降伏】
- 人間敵に morale / maxMorale を追加。
- 通常攻撃、強撃、崩し等で士気低下。
- 「降伏を促す」コマンドを追加。
- 士気0でHPを0にせず戦闘終了。
- 街道のならず者で実際に試せる。

【最初の1時間】
- 街道のランダムエンカウントを停止しシンボル戦へ統一。
- 古砦を本筋必須から外して寄り道化。
- 灰牙狼撃破後、そのまま街道北端→高台→王都へ進める。
- 王都任命式→白鹿亭の夜イベントまで一本の導線に接続。
- 白鹿亭の夜イベント完了を alphaHourComplete として保存。

【サウンド】
- 村 / 街道 / 王都 / 戦闘の仮BGMモチーフをWeb Audioで切替。
- 斬撃 / 命中 / 魔法 / 回復 / 決定 / 勝利の仮SEを追加。
- SOUND ON/OFFボタンを追加。

【互換性】
- SAVE_SCHEMA 16。
- v15以前の保存データを継続読み込み可能。

灰冠の勇者たち Vertical Slice v3 修正内容

1. 戦闘への切り替えを明確化
- 戦闘開始時に暗転して「ENCOUNTER」と敵名を大きく表示。
- 戦闘UIをページ下部ではなくゲーム画面内の全面オーバーレイへ移動。
- 現在の敵名、ターン、味方、敵、行動コマンド、戦闘ログを1画面内に集約。

2. 戻れない問題を修正
- リュネ村北門から街道へ進んだ後、街道南端からリュネ村へ戻れる。
- 街道と古砦跡を往復できる。
- 古砦跡を抜けた後も北側旧街道から古砦へ戻れる。
- 縦切り版クリア画面を閉じた後も探索を継続できる。

3. 古砦跡を拡張
- 入ってすぐボス戦 → そのままクリア、という構成を廃止。
- 西側：洞窟コウモリ + 開閉機構。
- 東側：石殻ムカデ + 開閉機構。
- 両方の機構を作動させると中央鉄格子が開く。
- 宝箱2個、古い王国軍旗、空の保存食箱などの調査ポイントを追加。
- 奥のボスを「古砦の主・灰角獣」に変更。
- ボス撃破後、北出口まで実際に歩いて抜ける。
- 北側に短い旧街道マップと王国軍斥候を追加。

4. リュネ村の人口・生活感を増加
- 子ども：ミカ、レン、ルルを追加。
- 大人：パン屋のエダ、農夫のボル、老婆ナナ、兵士の母、帰還兵ガルドを追加。
- 既存の孤児院の子も含め、子どもの姿が複数見える村にした。
- 畑、井戸、洗濯物、花、柵を追加。
- 戦争や食料不足を、説明文だけでなく住民の日常会話から感じられるようにした。

5. その他
- 戦闘後の全回復を廃止し、少量回復へ変更。複数戦闘の意味を持たせた。
- 古いセーブデータ向けに不足フラグを補う読み込み処理を追加。

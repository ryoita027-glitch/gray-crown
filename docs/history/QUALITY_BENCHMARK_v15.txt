『灰冠の勇者たち』製品版品質ベンチマーク v15

【Phase 1 — 基盤】
・1入力=1マス。論理座標が描画を大きく追い越さない。
・上下左右の向きを保持し、停止時も最後の向きの待機フレームを使う。
・カメラと4人隊列は補間する。
・通常セーブ＋バックアップ、破損値補正、壁内座標補正を維持する。
・新規マップ／新規イベント追加後は必須地点への到達性をテストする。

【Phase 2 — 縦スライスの見た目】
基準対象: リュネ村 / 王都への街道 / アルディナ王都 / 家の中
・主要4人は assets/hero_party_walk.png の32x32・4方向・3フレームスプライトを使用。
・移動中のみ足踏みし、停止時は各方向の中央フレームで静止する。
・地面は1タイル単位の黒枠を見せない。大きな汚れ、轍、影を複数タイルに跨がせる。
・街道は中央直線ではなく、蛇行、路肩、脇の空地、旅の痕跡を持つ。
・町はランドマーク＋生活物＋視覚アクセントを同時に置く。
・王都は王城正門 / 式典広場 / 市場 / 軍務街が色・密度・用途で判別できる。
・室内は床、収納、食器、光源、家具、生活物から用途が読める。

【Phase 3 — RPG基本仕様】
・経験値: EXP_TABLE（累積経験値）を唯一のレベル閾値とする。
・成長: partyBase + LEVEL_GROWTH。calculateBaseStatsAtLevel()で基準値を再現できる。
・戦闘: RPG_RULES.damage と SKILLS / BATTLE_LOADOUTS を参照する。
・宝箱: TREASURE_DEFS + state.treasures + openTreasure()。個別の一回限り処理を増やさない。
・マップ移動: MAP_TRANSITIONS + useMapTransition()に移動先座標・向きを持たせる。
・探索設計: MAP_FEATURES + validateMapDesign()。最低1つの任意探索要素を必須とする。
・新マップ制作時は一本道だけにせず、NPC / 宝箱 / 脇道・ショートカットのいずれかをデータへ登録する。
